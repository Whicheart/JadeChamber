# 编码规范

## 命名规范

- Vue 组件使用 PascalCase。
- 变量和函数使用 camelCase。
- 常量根据实际语义使用 UPPER_SNAKE_CASE。
- 命名应清晰表达实际用途，避免无意义缩写。

## TypeScript

- 使用 TypeScript strict mode。
- 禁止随意使用 `any`，特殊情况必须说明并获得用户确认。
- API 请求和响应应具有明确类型。

## Vue 组件

- 使用 Vue 3 Composition API。
- 避免过度抽象。

### Composables

- 可复用的组合式逻辑放在 `src/composables/`。
- Composable 使用 `use` 前缀命名。
- 不将简单逻辑无意义地抽取为 Composable。

### SCSS

- 组件内部使用 `<style lang="scss" scoped>`。
- 全局样式统一放在 `src/styles/`。
- 全局变量、Mixin、Reset 和公共样式集中管理。
- 避免全局样式污染和重复定义。

### 注释

- 只为复杂逻辑、关键设计和必要约束添加注释。
- 不添加重复代码含义的无效注释。
